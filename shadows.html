¿Qué hace cada propiedad?

👇 inset (Sombra Interior)

Es una palabra clave que se usa dentro de box-shadow. Invierte la sombra para que se dibuje por dentro de la caja en lugar de por fuera.

🔍 scale() (Escalar)

Se usa dentro de la propiedad transform. Permite aumentar o disminuir el tamaño visual del elemento.

🚀 translate() (Mover)

Se usa dentro de transform para desplazar un elemento. Por ejemplo, translate(0px, -15px) lo mueve hacia arriba.

🖱️ :hover (Al pasar el ratón)

Es un "estado" que aplica estilos SÓLO cuando el puntero está encima. Combinado con transition, crea animaciones.

☑️ Checkboxes

Ocultamos el checkbox original y creamos uno falso. Usamos la pseudoclase :checked para encender el neón interior.

🔘 Radio Buttons

Igual que el checkbox pero agrupados por el atributo name para que solo puedas elegir uno. Tienen border-radius: 50%.

🗂️ Select Múltiple

El atributo multiple permite seleccionar varias opciones. Usamos sombras hundidas para enmarcar las selecciones brillantes.
